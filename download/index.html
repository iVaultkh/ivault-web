"Windows protected your PC" on the direct installer

The direct installer is not code-signed yet, so Windows SmartScreen warns before the first run. Click More info, then Run anyway. To check the file is ours, compare its SHA-256 with the SHA256SUMS file on the release. The Microsoft Store version has no warning.

Before you start

  • FFmpeg. iVault converts with FFmpeg, which is free. On Windows, download the "release essentials" build from gyan.dev, unzip it, and choose its bin folder in Settings → Conversion. The support guide walks through it.
  • Somewhere to upload. A storage account (Cloudflare R2, Amazon S3, MinIO, Telegram, Google Drive, OneDrive, GitHub, WebDAV) or just a folder on your computer or NAS.
  • Windows 10 version 1809 or later, on x64 or Arm64. WebView2 comes with Windows 11; the installer adds it on Windows 10 if it is missing.

macOS and Linux

iVault runs on macOS and Linux, but there are no ready-made downloads for them yet. They will appear on this page and in the changelog when they are.
